# 图神经网络中的消息传递

适用对象：已了解向量、均值和图的基本概念的本科生。
建议课时：45 分钟。

## 核心概念

图由节点和边组成。节点可以表示人、地点或物体，边表示它们之间的关系。
在图神经网络中，节点通常带有特征向量；消息传递利用图的连接关系更新这些特征。

一次消息传递通常包含三个步骤：构造消息、聚合邻居消息、更新节点表示。
消息可以由邻居的特征构造，也可以结合边的特征。常见的聚合方式包括求和、均值和最大值。
聚合函数通常需要对邻居排列不敏感，因为图中邻居通常没有固定顺序。
更新函数可以结合当前节点自身的旧特征与聚合后的邻居信息。

## 课堂计算案例

考虑无向链状图 A—B—C，节点初始标量特征分别为 A=2、B=4、C=6。
采用最简单的规则：新特征等于邻居旧特征的均值，不包含自身特征。
同一轮的所有节点同步更新，均使用上一轮的数据：

- A 只有邻居 B，因此 A 的新特征为 4。
- B 的邻居是 A、C，因此 B 的新特征为 (2+6)/2=4。
- C 只有邻居 B，因此 C 的新特征为 4。

这一规则是便于演示的特殊例子，不代表所有图神经网络的更新公式。

## 教学目标

1. 能区分节点特征、邻居和边。
2. 能用自己的话说明消息构造、聚合、更新三个步骤。
3. 能正确完成一次同步均值聚合，并解释为什么不能边算边使用本轮的新结果。
4. 能解释一轮与多轮消息传递的感受野差异。

## 常见误区

- 邻居均值不是全图所有节点的均值。
- 一轮同步更新不应读取同一轮刚更新的邻居特征。
- 是否加入自环、是否使用可训练权重，需要由具体模型定义。
- 多层消息传递可以引入更远邻居的信息，但层数增加不一定总能提高效果。

## 课堂活动

学生三人一组，分别扮演 A、B、C。先在纸上写下自己的旧特征，交换消息后再同时展示新特征。
交换节点标签的排列，检查均值聚合结果是否变化。最后讨论加入 A—C 连接后第一轮的结果。
